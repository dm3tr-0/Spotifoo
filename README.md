# Spotify "Premium" БЕСПЛАТНО на Android

## Что есть на текущий момент
- Проект вдохновлен https://spicetify.app/#install (для Windows/MacOS/Linux), оттуда позаимствована javascript инъекция (AdBlock в их магазине плагинов) для получения premium возможностей и блокировки рекламы
- Встроенно расширение ublock для дополнительной блокировки рекламы
- Можно выбирать любой трек, переключать треки сколько угодно раз, ставить повтор, выбирать место в треке и тд(этого нет в бесплатной подписке)

## Проблемы
- Возможности скачивать треки НЕТ и не будет (это нерешаемая проблема)
- Интерфейс приложения не адаптирован под телефоны
- По какой-то причине реклама время от времени все равно проскакивает (правда все равно не так часто, как на бесплатном плане)
